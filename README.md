# 🏦 Simple Bank Chatbot

> **A beginner-friendly rule-based Python banking chatbot.**

## Why I Built It

This was an early programming project created to move beyond isolated Python exercises and build a small interactive application.

A banking chatbot was a useful practice problem because it combines user input, conditions, functions, loops, state, validation and conversation flow.

## What It Demonstrates

- user input handling
- conditional logic
- functions
- loops
- basic validation
- rule-based conversation
- simple stateful interaction

## Architecture

```text
User Input
    │
    ▼
Input / Command Logic
    │
    ▼
Rule-Based Processing
    │
    ▼
Chatbot Response
```

## Technology

- Python
- functions
- conditions
- loops
- input validation
- rule-based logic

## Learning Outcome

The project helped establish a foundational pattern used in larger software systems:

**Input → Logic → State → Output**

It is intentionally not presented as a production banking application or an AI/LLM system.
